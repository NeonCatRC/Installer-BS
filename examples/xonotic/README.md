# Xonotic — «ответка» одной командой

Этот рецепт оборачивает **официальный prebuilt-релиз Xonotic** в один `.bs`-пакет: ноль компиляции,
ноль рытья в репозиториях, ноль чужих бинарей в гите. Прямой ответ на статью автора оригинала
«Почему Linux обречён…», где он собирал ровно эту игру — вручную, через 2000-строчный `installer.sh`,
с MD5-«защитой» и двумя перевыпусками.

Ключевой факт: **игру не нужно компилировать.** Апстрим раздаёт `xonotic-0.8.6.zip` с готовыми
бинарями под все платформы. Автор оригинала компилировал из исходников только редактор уровней
NetRadiant (и сам себе устроил «ад зависимостей»: рытьё в 89-ГБ локальной копии репы, провал сборки
под FreeBSD, падение на Fedora из-за `libGLU`). Сама игра — это распаковать и играть.

## Сборка

На Linux x86_64 (у нас — в контейнере `ubuntu:24.04`):

```sh
./bs make examples/xonotic/recipe
#   :: fetching https://dl.xonotic.org/xonotic-0.8.6.zip   (~1.18 GiB)
#   ok  source sha256 verified
#   ok  built xonotic-0.8.6-x86_64.bs
#   :: size: 1153 MiB
```

Скачивание кэшируется по sha256 (повторный `bs make` — офлайн). Упаковка — `tar.xz`; на ~1.2 ГБ это
~10 минут (как и у него: данные уже лежат в сжатых `.pk3`, поэтому жать особо нечего — ровно поэтому
его же замер дал `7-Zip` 1261 МБ против `tar.xz` 1264 МБ, разница 0.24 %).

## Провенанс и целостность

- Источник пинуется по **sha256** (`50850f8d…cbe964d`) в рецепте.
- Дополнительно загрузка сверяется с **SHA-512, опубликованным апстримом** на
  <https://dl.xonotic.org/xonotic-0.8.6.sha512> — реальная цепочка доверия, а не «MD5 рядом в скрипте».
- Готовый пакет подписывается настоящим **OpenPGP**:

```sh
./bs sign   xonotic-0.8.6-x86_64.bs      # -> .sig
./bs verify xonotic-0.8.6-x86_64.bs      # sha256 ok + OpenPGP good signature
./xonotic-0.8.6-x86_64.bs --check        # payload CRC (xz) + sha256-сайдкар + .sig
```

## Проверено end-to-end (реальный прогон, не «на глаз в VM»)

В чистом контейнере `ubuntu:24.04` пакет прошёл полный цикл:

- `--check` → `payload ok: 2899 member(s), container checksums intact` + sha256 + OpenPGP ✓
- `--install` (XDG) → приложение в `~/.local/share/installer-bs/xonotic`, лаунчер `~/.local/bin/xonotic`,
  второй лаунчер `xonotic-linux-dedicated.sh`, `.desktop` в меню, иконка в `hicolor/256x256`.
  **Ни одной папки в корне ФС.**
- запуск **dedicated-сервера headless** → движок поднялся и прочитал бандл-данные:
  `Game is Xonotic using base gamedir data` … `Xonotic Linux … release`.
- `--uninstall` → чисто: app-каталог и оба лаунчера удалены, хвостов нет.

## Сравнение с его пакетом «Xonotic» (Installer-SH)

| | Installer-SH (он) | Installer-BS (этот рецепт) |
|---|---|---|
| Сборка | NetRadiant из исходников + ручная правка `installer.sh` (~2000 строк) | один декларативный рецепт, **ноль компиляции** |
| Содержимое | game + editor + engine source в одном блобе | официальное дерево игры (верифицировано) |
| Целостность | **MD5**, «несколько проверок» | upstream **SHA-512** → sha256-пин + **OpenPGP**-подпись |
| Бинари в гите | вкомпиленный 7-Zip (~10 МБ) | **ноль** |
| Воспроизводимость | не мог получить тот же MD5 дважды | bit-reproducible (`--sort`, `SOURCE_DATE_EPOCH`) |
| Перевыпуски релиза | **2** (версия-«опечатка» + `ISHMoveHomeDir`) | — |
| Размер | 1264 МБ (tar.xz) / 1261 (7-Zip) | **1153 MiB** |
| glibc-потолок | выяснял вручную («ниже Debian 11 — GLIBC») | `min_glibc=2.29` авто-guard в манифесте |
| Тест | визуально в VM Live CD | install/run(dedicated)/uninstall в контейнере + проверка подписи |

## Честно (правило пары)

- **Размер — не главный выигрыш.** Данные игры — одинаковые `.pk3`, они уже сжаты; наш `.bs` меньше
  лишь за счёт `xz` на не-`pk3` частях. Суть не в «меньше», а в честности: подписано, воспроизводимо,
  без компиляции, без чужих бинарей, один рецепт вместо правки монолита.
- **Зависимости мы не «победили».** Dedicated-сервер линкуется только с базовыми либами и идёт
  везде. SDL-клиенту нужны системный `libSDL2` и — в рантайме — **драйверный `libGL` хоста**.
  `libSDL2` можно вложить в `lib/`; драйвер GPU — нельзя, он всегда хостовый. Именно поэтому 3D-софт
  нельзя сделать «работающим везде» одним бандлингом — и именно на этом классе (отсутствующая
  GL-смежная `libGLU`) у автора оригинала упал NetRadiant на Fedora.
- Мы пакуем **полное** официальное дерево (включая `source/`) ради точного провенанса; при желании
  `source/` можно не класть (апстрим отдаёт его отдельным `-source.zip`).

## Воспроизвести

Артефакт в гит не коммитим (1.2 ГБ). Любой может собрать тот же байт-в-байт пакет:

```sh
./bs make examples/xonotic/recipe      # на Linux x86_64
```
